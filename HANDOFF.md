# FusionDrop handoff

## Product
Offline Android phone-to-phone file transfer. App name FusionDrop. Original user-supplied Dragon Ball image is stored unchanged at `app/src/main/res/drawable-nodpi/fusiondrop_logo.jpg`; do not edit the image. Launcher art was generated by letterboxing the original into a dark square so the full composition remains visible.

## Stack
Kotlin 2.0.21, AGP 8.7.3, Gradle 8.9, Compose BOM 2024.12.01, CameraX 1.4.1, ZXing core 3.5.3, minSdk 24, target/compile 34, Java 17. CI uses Gradle installed by setup-gradle, not wrapper.

## Key source files
- `MainActivity.kt`: Compose screens and flow wiring
- `connection/TransferConnection.kt`: transport abstraction
- `connection/WifiDirectConnection.kt`: Wi-Fi Direct group setup and socket abstraction
- `transfer/TransferProtocol.kt`: one-connection sequential file protocol and streaming
- `transfer/TransferService.kt`: dataSync foreground service
- `scanner/QrScanner.kt`: CameraX + ZXing QR scanning

## Known incomplete items (must fix before production)
1. Wi-Fi Direct association is implemented with `WifiNetworkSpecifier` on API 29+ and `WifiP2pManager.connect` on API 24–28, but requires physical-device validation.
2. Sender advertises the group owner address, SSID, passphrase, IP and port. The IP currently assumes the common P2P gateway `192.168.49.1`; validate OEM variations.
3. Wi-Fi and partial wake locks are acquired by the foreground service and released on service destruction; ensure every cancellation/error path stops the service.
4. Update foreground notification with progress and a cancel PendingIntent; wire cancellation to socket close.
5. Add end-to-end SHA-256 digest framing and receiver verification; currently setting is UI-only.
6. Persist transfer history and settings; currently history is process-memory only.
7. Handle Android 9 and below destination storage; current MediaStore Downloads path is Android 10+.
8. Improve duplicate-name handling to avoid query/insert race. Unknown-size picker sources are staged to cache before transfer; add cache cleanup on every exceptional path.
9. Verify permission denial/rationale/settings handling; current prompts are basic. Full Bengali UI localization is still pending.
10. Add instrumented tests and run on two physical devices.
11. Finish live per-file status, ETA/average speed, and cancel propagation.

## Protocol v1
Magic `FDRP`, 32-bit file count, 64-bit total size, then for each file: 32-bit UTF-8 name byte length, name bytes, 64-bit file size, then exact raw file bytes. One TCP connection; files sequential. This version needs robust framing for unknown-length sources and optional checksum metadata before release.

## Build
